# 미대 졸업전시 캘린더 2026

2026년 가을 11개 대학, 30개 미술·디자인 졸업전시 일정을 한 달력에 모았습니다.

- 막대를 누르면 전시명, 기간, 관람 시간, 오프닝, 장소가 열립니다.
- **동선짜기**: 구나 동 이름(예: 종로구, 인사동, 대학로)을 입력하면 같은 날 그 지역에서 함께 볼 수 있는 전시를 순서대로 묶어 줍니다.

👉 https://entjs-whale.github.io/art-grad-calendar/

## 출처

전시 정보는 [@cultureart4u](https://www.instagram.com/cultureart4u/) 인스타그램 게시물에 소개된 각 학과 졸업전시 포스터와 홍익대학교 미술대학 졸업전시 일정표를 옮겨 정리했습니다. 출처끼리 시간이 다른 전시는 상세 정보에 함께 적었습니다. 방문 전 각 학과 공식 계정을 확인하세요.
